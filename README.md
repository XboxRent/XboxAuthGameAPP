# Xbox AutoPilot

Мобильная веб-панель для управления собственной Xbox-консолью через отдельную XRemote JS-сессию на VPS.

## Как устроено

- index.html — сайт, открывается на компьютере, iPhone и Android.
- xremote-vps/ — сервер и Chromium worker с @yowari/xremote; именно он создаёт отдельную Remote Play-сессию и отправляет нажатия.
- companion/ — отдельный read-only помощник для UPnP-обнаружения в локальной сети; для XRemote VPS не требуется.

## Запуск XRemote

Инструкция по VPS, HTTPS, ключам, подключению сайта и API: xremote-vps/README.md.

Важно: XRemote не использует уже открытую вкладку xbox.com/remoteplay. Он создаёт отдельную сессию и требует действительный XRemote-совместимый OAuth-токен, который хранится только на VPS. Реальная работа с конкретной консолью требует отдельной проверки на устройстве.

## iPhone и Android

Размести корневой сайт на HTTPS и добавь его на главный экран через меню браузера. В разделе «Автоматическое управление» укажи HTTPS-адрес VPS и API_KEY. Телефон отправляет сценарий серверу; телефон не обязан оставаться на странице во время выполнения сценария.
