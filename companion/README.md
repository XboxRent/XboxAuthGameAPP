# Xbox AutoPilot — локальный компонент

Этот компонент выполняет **только read-only UPnP/SSDP обнаружение** в локальной сети. Он не управляет консолью, не получает учётные данные и не утверждает, что Remote Play запущен.

## Запуск

1. Убедись, что компьютер и Xbox подключены к одной домашней сети (не гостевой Wi‑Fi).
2. Установи Python 3.9 или новее на компьютере.
3. Открой терминал в корне репозитория и запусти:

   ```bash
   python companion/server.py
   ```

   На Windows, если команда `python` не найдена, попробуй `py companion/server.py`.

4. Узнай локальный IPv4-адрес компьютера:
   - Windows: `ipconfig` → IPv4-адрес Wi‑Fi/Ethernet.
   - macOS: Настройки системы → Wi‑Fi → Подробнее → TCP/IP.
   - Linux: `hostname -I`.
5. На iPhone, подключённом к той же сети Wi‑Fi, открой `http://АДРЕС-КОМПЬЮТЕРА:8765/`.

## Важно

- Для диагностики через локальный компонент открывай страницу **с адреса компьютера**, а не GitHub Pages: это позволяет странице и API работать с одного origin без смешанного HTTP/HTTPS-контента.
- Разреши локальный сетевой доступ, если iOS спросит. На компьютере разреши входящие подключения Python в частной домашней сети.
- Не открывай порт 8765 в интернет и не настраивай переадресацию портов на роутере.
- SSDP/UPnP может быть отключён роутером или консолью. «Не обнаружен» означает только отсутствие подходящего объявления, а не то, что Xbox выключен.
- Проверка активного сеанса Remote Play намеренно остаётся «не подтверждена»: у публичной веб-страницы нет официального сигнала о состоянии другой вкладки.
- На GitHub Pages локальная проверка не заработает напрямую; используй адрес локального компонента выше.

Компонент использует только стандартную библиотеку Python и не требует установки пакетов.
