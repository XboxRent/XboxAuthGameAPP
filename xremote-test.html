Диагностика ещё не запускалась.
Этот тест создаёт только локальное WebRTC-соединение между двумя объектами браузера на этом iPhone. Он не подключается к Xbox, не отправляет команды на консоль, не запрашивает пароль Microsoft и не собирает токены.

Успешный локальный тест подтверждает базовые API Safari, но не гарантирует совместимость XRemote JS с Xbox-сервисами, сетевой авторизацией, ICE-настройками или видеопотоком консоли.

Независимый проект · Не связан с Microsoft
