Xbox AutoPilot 3.2

Исправлено: ограничение проверки 4,5 секунды, чтобы не зависать при отсутствии сети; обновлён Service Worker для HTTPS.

Для работы откройте index.html через HTTPS-хостинг в Safari на iPhone. PWA устанавливается через меню «Поделиться» → «На экран Домой».

Приложение является информационной панелью/инструкцией для Xbox Remote Play. Safari не позволяет веб-странице автоматически подключаться к Xbox или управлять консолью без действий пользователя.
